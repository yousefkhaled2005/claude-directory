**claude-directory** is an open-source reference collection of production-grade, AI-generated front-end components, creative shaders, and responsive templates. Every experiment is completely self-contained, bundles its originating prompt in `prompt.md`, and includes local verification checks.

Built with **React, Next.js, TypeScript, Vite, Tailwind CSS, Three.js, Framer Motion, and GSAP** — demonstrating what frontier reasoning models can design and construct autonomously on the modern web.

## Categories

- [**Hero sections**](./hero-sections/) — Cinematic viewport experiences, animated typography, and dynamic streaming banners.
- [**Landing pages**](./landing-pages/) — Full-page multi-section SaaS marketing and product showcase templates.
- [**Shaders**](./shaders/) — Real-time GLSL canvas shaders, raymarching, liquid metal, and procedural effects.
- [**3D & games**](./3d-games/) — Interactive Three.js worlds, procedural landscapes, and physics simulations.
- [**Animations & loaders**](./animations-loaders/) — Micro-interactions, spring physics, and canvas particle loaders.
- [**Components & UI**](./components-ui/) — Modular buttons, search dialogs, bento grids, and interactive widgets.
- [**Portfolios**](./portfolios/) — Creative developer portfolios, editorial layouts, and kinetic typography.

## Architecture & Verification

Each project folder contains:
- `prompt.md` — The prompt engineering instructions and system guidelines used to generate the interface.
- Complete standalone source code with zero external network dependencies for offline reproducibility.
- Automated poster generation via `scripts/generate-posters/` and metadata synchronization in `posters.json`.
